# E-Commerce API & Database QA Automation Framework

A Python-based QA automation framework for testing REST APIs and validating backend data stored in SQLite.

## Tech Stack

- Python
- Flask
- PyTest
- Requests
- SQLite
- SQL
- pytest-html
- Git/GitHub

## Project Architecture

```text
API Request
     ↓
Flask REST API
     ↓
Response Validation
     ↓
SQLite Database
     ↓
SQL Validation
     ↓
PyTest
     ↓
HTML Test Report
